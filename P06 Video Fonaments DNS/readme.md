# P06: Vídeo - Fonaments del DNS

## 📝 Breu Descripció
A l'activitat **"T06: Fonaments del DNS"**, l'equip d'**EverPia** va desenvolupar un recurs multimèdia sota l'encàrrec de **Digicorp**, orientat a la formació interna del seu personal tècnic en els conceptes clau i el funcionament bàsic del sistema de noms de domini (DNS).

Aquest material audiovisual representa un producte d'alt valor tècnic i pedagògic. Per aquest motiu, l'objectiu d'aquest lliurament és integrar-lo de forma directa al vostre **portfoli personal i currículum professional**. Progressar dins el sector IT implica fer valdre les millors solucions i accions que es van construint i consolidant al llarg del temps.

Per garantir que el departament tècnic i els avaluadors puguin visualitzar correctament el recurs, s'han de seguir les següents indicacions:

* El vídeo ha d'estar allotjat a una plataforma de contingut multimèdia. 
* Es recomana utilitzar de forma nativa l'eina **Microsoft Stream**, inclosa dins de les llicències d'Office 365 de l'escola/empresa.

### 2. Gestió de Permisos (Imprescindible)
* > ⚠️ **Atenció:** Abans de fer el lliurament, cal **assegurar i verificar els permisos de visualització** de l'enllaç generat. Si el consultor o professor no té accés al contingut adjunt, la tasca es considerarà com a no lliurada.
